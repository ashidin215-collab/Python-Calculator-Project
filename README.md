# Python-Calculator-Project
## Project Description
This is a simple calculator application developed using Python. It performs basic mathematical operations and helps users calculate numbers easily.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User-friendly interface
- Displays calculation results

## Technologies Used
- Python

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the Python file.
4. Follow the instructions to perform calculations.
